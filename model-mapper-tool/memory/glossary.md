# Glossary

Terms as used within 4D-Bio. Where a term is not yet settled, that is noted and it
also appears in [`open-questions.md`](open-questions.md).

| Term | Meaning in 4D-Bio |
|---|---|
| **4D-Bio** | The practice model this repo publishes. Short name; full name "A Practice Model for AI-Augmented Bioinformatics". |
| **Capability** | One of the four D's: Delegation, Description, Discernment, Diligence. Top level; one site page each. From Anthropic's 4D framework. |
| **Practice area** | Level 1. A professional situation where a capability applies. Gerund-phrased. `##` heading on the site. |
| **Category / group** | Level 2. A cluster of related competencies inside a practice area. Either *author-defined* or *framework-derived*. (Term not yet fixed by the author.) |
| **Competency** | Level 3. The atomic skill. Either a *linked competency* or a *plain-text competency*. |
| **Linked competency** | A competency that exists in an external framework; rendered as a hyperlink to that framework's entry, using its identifier and wording. |
| **Plain-text competency** | A competency authored by 4D-Bio because no referenced framework catalogues it; no link. |
| **Anthropic definition** | The verbatim definition of a capability from Anthropic's 4D framework. |
| **Bioinformatics definition** | The author's 1–3 sentence framing of what a capability means in bioinformatics. |
| **4D framework** | Anthropic's framework for AI fluency (Dakan, Feller, Anthropic). Supplies the four capabilities. |
| **ISCB Competency Framework v3.0** | The bioinformatics profession's competency catalogue (Brooksbank et al. 2024). Source of most linked competencies. |
| **ISCB code** | Domain letter + level, e.g. `D3`. All cited codes end in `3`. |
| **ISCB domain** | A letter-grouped area of the ISCB framework: Bioscience (A–C), Data Science (D–F?), Computer Science (G–I), Professional Conduct (J–M). Confirm boundaries. |
| **ACTIVE Framework** | A pedagogical framework for AI use; supplies practices like "Verification Confidence Calibration". Acronym expansion unconfirmed. |
| **model-mapper-tool** | The future tool (this folder) for representing 4D-Bio as data and mapping it to external frameworks. |
| **crosswalk** | A mapping between 4D-Bio competencies and another framework's competencies, in either direction. |
