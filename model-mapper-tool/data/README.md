# data/

Structured representations of the 4D-Bio model. Empty for now.

| Subfolder | Contents |
|---|---|
| `raw/` | Untouched source exports — e.g. the author's original spreadsheet. The cleanest source for the practice-area → group → competency grouping. |
| `processed/` | Normalized, machine-readable model data (one file per capability suggested). Generated from `raw/` and kept in sync with the site under `../../docs/`. |
| `schema/` | The schema `processed/` conforms to. Draft: [`../memory/proposed-data-model.md`](../memory/proposed-data-model.md). |

See [`../memory/hierarchy.md`](../memory/hierarchy.md) and
[`../memory/content-inventory.md`](../memory/content-inventory.md) before adding data.
